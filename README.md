## 新闻/活动统一工作台（2026-10-20）

后台统一使用“新闻/活动”，新建时选择发布位置：新闻进入最新动态与新闻页，活动进入实验室现场与文化页；两者共用富文本、预览、核查发布和修订历史。列表每页10条，支持位置和状态筛选。毕业合影与东湖团建已迁入统一入口，维持待审草稿及照片待核状态。

更新先执行 `npm run db:migrate`（包含011迁移）；编辑器源代码改动后在 `frontend/admin` 执行 `npm run build`。旧相册编辑接口已退役；活动导入脚本和联调用例改用统一新闻接口。`npm run test:news-activities` 覆盖发布分流、草稿隔离和图片权限。

编辑器支持图文混选高亮、“全选图文”和复制粘贴布局保留，长文保存/返回入口保持可见；当前公开站与工作台均加入回到顶部按钮。图片位置调整使用剪切、粘贴。
