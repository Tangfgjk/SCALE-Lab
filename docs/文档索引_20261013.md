- 文档文件名使用“内容主题_YYYYMMDD.md”。同一天的后续修订直接更新文件，并在 Git 历史中追踪；跨日期的重要修订可产生新的日期版本。
- 以后确有需要时再增加日志、测试等目录；当前不为尚不存在的流程创建空文档。
