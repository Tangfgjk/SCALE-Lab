# 博士后栏目与孟皓成员详情实现记录

日期：2026-10-20。状态：本地已实现并发布孟皓中文成员档案；本轮代码尚未提交推送。

## 需求与来源

用户提供三页《孟皓_个人简历.pdf》和指定JPG头像，明确说明为本组新来的博士后，要求在教师之后设博士后栏目并提供详情按钮。

- 当前身份“博士后”依据用户说明。原PDF为博士后申请简历，其中“拟研究项目”保留为研究计划，不改写成已完成成果。
- PDF三页均已提取文字并渲染为图片逐页核对。新详情包含教育经历、研究基础、11项代表性论文、项目经历、专利与竞赛、学术及教学服务、研究计划。
- 论文只保留简历提供的题名、年份、发表载体及本人角色，没有补造DOI、期刊分区或会议等级，也未把全部条目统一宣称为已发表。
- 私人联系方式、出生年月、性别/民族、政治面貌等未录入公开资料；完整PDF未复制到公开目录。联系方式字段当前留空，后续可通过后台编辑并按字段授权发布。
- 原PDF里的证件照未用作头像；实际使用用户另外提供的正装照片，保持原图内容，通过现有媒体库生成网站文件。

## 实现

1. 新迁移`010_postdoc_members.sql`为成员类别增加`postdoc`，不更改旧迁移。
2. 后台类别选择增加“博士后”；公开顺序为导师、科研人员、博士后、在读学生、毕业校友。
3. 新字段`profileDetails`为选填文本，最多20000字，随每次成员修订存入`content_localizations.extra_json`。支持`## 小标题`与`- 条目`，在后台“成员详情”维护。
4. 详情沿用简介的bio公开授权；撤销简介授权会同时隐藏详情及详情入口。公开成员列表只返回hasDetails标记，具体正文由公开详情接口返回，避免每次团队页加载完整长文。
5. 新页面`member.html?slug=meng-hao`包含头像、简介、研究标签、章节目录与详细正文；有详情的其他成员也可复用入口。详情渲染采用textContent，不执行文本中的HTML。
6. 上传头像后，通过成员管理API建档、记录profile/bio/photo的用户指示依据、核查并发布中文版本。没有创建英文翻译；英文页正确提示该语言尚无公开资料。
