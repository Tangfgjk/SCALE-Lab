# SCALE Lab V3 相对 V2 的变更与完成情况

更新日期：2026-10-15  
基线分支：`V2-20261014`  
基线提交：`27ec522`

## 1. 总体结论

本轮在 V2 新闻编辑与内容发布流程之上，完成了“媒体资产管理 → 新闻/相册引用 → 授权核查 → 发布 → 公开渲染 → 停用后安全降级”的第一版闭环。V3 当前已经可以作为媒体库和新闻图片引用的开发验收版本继续使用；移动端视觉回归、第二个业务模块接入和首页封面缩略图样式仍保留为后续工作。

## 2. 相对 V2 的主要变化

| 领域 | V2 基线 | V3 本轮完成内容 |
| --- | --- | --- |
| 新闻正文 | 标题、摘要、纯文本正文；后台预览为简化文本视图 | TipTap 结构化富文本；段落、H2/H3、粗体、斜体、下划线、删除线、列表、引用、分隔线、链接、对齐、撤销/重做；实时预览与桌面/手机宽度切换 |
| 图片编辑 | 新闻正文不能引用图片 | 封面图片和正文插图均从媒体库选择；图片支持图注、宽度档位和左右/居中对齐 |
| 媒体库 | 资产列表和授权流程 | 媒体库、树形文件夹、重命名、移动、搜索、状态/归档筛选、分页、引用查询；资产以不可变 UUID 关联 |
| 授权发布 | 已有媒体授权能力 | 新闻保存时检查资产存在；核查和发布时再次检查启用、归档和版权/人物授权；未授权图片不能发布 |
| 活动相册 | 使用相册页面原有图片选择 | 复用共享媒体选择器和媒体资产；相册仍独立保存活动信息、封面顺序和逐图说明 |
| 公开新闻 | 详情页渲染纯文本正文 | 公开详情页使用安全结构化渲染器，解析封面和正文图片；图片失效时显示受控占位，不信任正文中的任意 URL |
| 历史兼容 | 旧新闻只有 `body` 纯文本 | 保留 `body` 兼容字段；没有富文本 JSON 的旧新闻仍可读取和编辑 |
| 数据库 | `news_revisions.cover_asset_id` 仅为预留字段 | 新增媒体库/文件夹字段和新闻修订图片引用表；保留历史修订引用，文件夹移动或重命名不改变引用 |
| 工程验证 | V2 新闻、相册等基础冒烟测试 | 增加新闻富文本图片专项测试、迁移记录、验收文档和问题知识库记录 |

## 3. 主要代码和数据交付

### 数据库与服务端

- `frontend/server/db/migrations/008_media_library_folders.sql`：媒体库、树形文件夹、资产展示名称、归档和默认位置迁移。
- `frontend/server/db/migrations/009_news_media.sql`：新闻封面外键、新闻修订级图片引用和历史封面回填。
- `frontend/server/media.js`：媒体库/文件夹接口、资产整理、分页筛选、归档、授权状态和引用查询扩展。
- `frontend/server/news.js`：新闻富文本、封面/正文图片引用、修订媒体校验、核查/发布授权复核和公开详情媒体返回。
- `frontend/server/rich-text.js`：结构化正文白名单、链接协议、图片资产 UUID、节点深度、数量和大小校验。
- `frontend/server/platform.js`：共享渲染器静态资源路由。

### 管理后台与公开站

- `frontend/admin/editor-src/rich-editor.js`、`editor.bundle.js`、`rich-editor.css`：富文本编辑器、工具栏和图片设置。
- `frontend/admin/media-browser.js`：新闻、活动相册共用的媒体选择器和上传入口。
- `frontend/admin/app.js`、`media-admin.js`、`album-admin.js`、`index.html`：新闻封面/正文图片、媒体库整理和相册选图界面。
- `frontend/shared/rich-renderer.js`、`rich-renderer.css`：后台预览和公开新闻详情共用的安全渲染规则。
- `frontend/visual-preview-20261013/news.html`、`assets/js/news-detail.js`：公开新闻封面、正文图片和失效占位。

## 5. 尚未纳入本轮完成定义的内容

1. 390px 移动端的完整视觉回归仍需单独执行。
2. 研究方向或项目的 Standard 富文本示范接入尚未实施。
3. 首页新闻列表目前保持 V2 的日期、标题、摘要展示；是否加入封面缩略图需要确认最终版式。
4. 尚未完成通过真实浏览器操作上传、选择、保存并发布一篇带图片新闻的完整 UI E2E；服务端专项测试已覆盖对应业务闭环。

以上项目不影响本轮媒体库、新闻图片引用和活动相册共享选择器的已完成范围。

## 6. 运行提示

本地服务需要使用项目 README 说明的 `DATABASE_URL`、管理员会话和 PostgreSQL 容器配置；数据库密码不写入代码或文档。迁移应通过 `frontend/server` 下的 `npm run db:migrate` 执行，服务通过 `PORT=3004` 启动时访问 `http://127.0.0.1:3004/`。
