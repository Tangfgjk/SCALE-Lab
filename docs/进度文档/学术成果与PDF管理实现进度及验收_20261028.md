日期：2026-10-28；分支：V5-20261020；本地正式开发入口：http://127.0.0.1:3004/ 。

## 已实现范围

| 项目 | 实现情况 |
| --- | --- |
| PDF 资源管理 | 独立资源库；上传、搜索、状态筛选、每页 10 条、名称/文件夹/版本/来源、引用历史、公开许可和停用 |
| 上传检查 | 单文件 25 MB；扩展名、MIME、文件头和解析验证；拒绝加密、脚本、表单、嵌入附件和不支持的 URI 协议；独立解析线程限时限内存；SHA-256 去重 |
| 成果类型 | 原论文兼容；新增专利、软件著作权；按类型切换字段；富文本正文、封面、关键词、代码和演示链接 |
| 附件引用 | 一个成果可关联多个 PDF，一个 PDF 可被多个成果复用；引用可设为仅后台；修订保存附件关系 |
| 关联 | 关联研究方向、科研项目和团队成员；公开方向/项目详情反向显示相关成果；禁止内容关联自己 |
| 精选与排序 | 成果精选开关与数字排序；如站点设置指定精选成果标识，则优先按该列表展示，否则使用成果精选设置 |
| 前台 | 分类、年份、方向、关键词筛选，每页 10 条；成果详情；复制引用；按需加载 PDF.js 预览，上一页/下一页，另开与下载 |
| 兼容导出 | GitHub Pages 导出公开成果详情和公开 PDF，支持仓库子路径；本轮只作本地导出验证，未更新远端静态站 |

## 架构与数据

- `backend/db/migrations/013_research_documents.sql`：新增 documents、research_revision_documents、research_revision_links、research_revision_assets；publication_revisions 增加 achievement_type、metadata、featured、display_order。旧论文默认 paper，不清空旧表。
- `backend/documents.js`：受登录保护的文档管理及按公开修订授权的文件读取。
- `backend/modules/research/`：成果字段校验、引用关系与公开数据补充、PDF 解析线程。
- `frontend/admin/documents-admin.js`、`research-admin.js`：资源管理和成果编辑。
- `frontend/shared/research-article.js`：后台与前台共用成果内容渲染；PDF.js 字体、CMap、WASM、worker 和许可证随构建提供，不依赖外部 CDN。
- PDF 字节在 MEDIA_ROOT/documents/YYYY/MM/ 下；数据库只存元数据及引用。因此现有数据库与媒体成套备份可同时保护 PDF。代码提交不包含这些业务文件。

管理接口：`/api/admin/v1/documents`（列表/上传），`/:id`（元数据），`/:id/access`（公开设置），`/:id/usage`（引用历史），`/:id/file`（后台文件）。

公开文件接口：`/api/v1/publications/:slug/documents/:id/file?locale=zh`，添加 `download=1` 下载。必须同时满足：该语言成果有公开版本、此版本关联该 PDF 且勾选公开、文档允许公开且已启用。不提供可绕开成果状态的通用公开 PDF 地址。
