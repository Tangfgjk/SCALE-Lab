## 本阶段完成

1. 公开站四页及内容工作台使用同一 PostgreSQL 内容源；新闻、研究方向、论文、项目、成员、媒体、活动相册、站点设置和账号审计具备基础写入／读取闭环。
2. 王志锋教师主页来源的导师、学生、校友及精选成果已发布；按用户新指示增列刘晓雪、熊宇轩，教师 3 张肖像通过媒体库与成员修订关联。
3. 全套九个既有冒烟测试与新增成员头像测试通过；桌面和手机共 10 个入口场景无脚本错误和横向溢出。
4. 后台成员编辑可选择已启用媒体，照片字段需单独登记依据；媒体停用可立即隐藏公开头像。

## 下一阶段顺序

1. **内容体验**：实验室负责人和 1–2 位内容人员实际浏览、编辑、发布；记录语言、可读性、导航、表单与错误提示的问题。先补正式新闻、活动照片、联系渠道。
2. **功能收尾**：补齐列表分页、内容关联／首页精选、图片替换、键盘与屏幕阅读器流程；在真实内容规模下验证检索和排序。
3. **英文内容**：准备并核查正式译文，按语言独立发布；中文版上线不依赖英文版同日完成。
4. **部署准备**：确定云服务器、域名、HTTPS、备份和恢复责任，关闭本地初始凭据，配置生产密钥与运维监控。

目前“整体功能初步完成”指首版模块的核心链条可供本地体验；不表示真实内容、无障碍、英文、云端与长期运维已完成。
