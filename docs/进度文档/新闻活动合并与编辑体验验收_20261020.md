## 重跑方法

在 `frontend/server` 配置本地 `TEST_BASE_URL`、`ADMIN_LOGIN`、`ADMIN_PASSWORD` 后：

```text
npm run test:news-activities
npm run test:news-workflow
npm run test:content-lists
npm run test:bilingual-news
npm run test:news-media
```

浏览器登录后台后运行 `tests/editor-mixed-selection.browser.js` 的异步函数，验证共享编辑器；`tests/news-article-duplicate.browser.js` 可验证共享文章渲染的摘要/封面去重。

`tests/activity-public-ui.browser.js` 使用浏览器拦截的合成活动，验证文化页到统一详情的链路、手机布局及回到顶部；不写数据库，执行后恢复真实后台页面。

迁移专用检查：执行迁移前设置 `DATABASE_URL` 并运行 `node tests/activity-migration-preservation.js --before`，迁移后运行不带参数的同一命令。快照仅保存在忽略目录，使用已有快照时不要再次加 `--before` 覆盖基线；后续人工编辑会使该基线检查失效，应按新的变更另行验收。

本轮快照：`frontend/server/storage/import-reports/unified-before-20261020.json`。桌面和手机截图：同目录 `unified-editor-desktop-20261020.png`、`unified-editor-mobile-20261020.png`。这些文件仅存在本地，Git推送不包含它们。

4. 本轮不执行Git提交推送；沿用当前工作分支，包含此前未提交工作。

## 同日补充：长文左侧导航

用户反馈长文滚动后只剩左侧背景、导航按钮不可见。桌面端（宽度大于850px）将侧栏设为视口内吸顶、高度为视口高度，菜单过长时独立纵向滚动；手机保留原横向菜单布局。

实测：1440×900窗口滚动2400px后侧栏顶部仍为0，新闻/活动按钮处于可见范围；1440×500窗口侧栏可独立滚动到操作记录；390×844窗口不启用桌面吸顶规则，无横向溢出。未修改活动草稿或图片公开状态。

图片预览中的“待核／未获准公开”提示针对媒体资产：需要在媒体资源中核对来源、版权及人物公开依据并启用图片。它与文章“核查当前修订”分开；活动迁移和编辑不会自动批准照片公开。
