# 网站现状评估与问题清单

检查日期：2026-10-13。范围：本地 `frontend/`、`frontend/server/`，以及桌面与 390px 宽浏览器页面。此处记录已观察事实，不代表外部内容已经核验。

## 1. 已实现

- 四个静态页面：`index.html`、`people.html`、`research.html`、`culture.html`，本地 HTTP 访问正常。
- 首页、人员、研究和文化的主要模块及响应式 CSS 已具备；研究页的三个模拟指标可切换。
- 页面有中文／英文切换，但尚未形成完整双语内容体系。
- Express 提供 `/api/v1` 只读接口和 `/healthz`，本地检查返回 200；管理端仅返回未授权占位响应。
- 前端读取 `frontend/assets/js/data.js`；API 读取 `frontend/server/data/content.json`。两份数据目前独立维护。
