## 动画制作与来源

用户提供扩展名为jpg的GIF，源文件224帧、6.72秒、8,961,395字节。已查看每10帧的联系表及150～161帧逐帧图，确认第154帧开始混入“人工智能教育学部”与二维码片尾。

- 保留原GIF第12～153帧，去掉开头短暂空白及整个学部片尾；校园牌匾原有“华中师范大学”文字保留。
- 使用H.264/yuv420p、faststart、无音轨，导出MP4。原宽1025为奇数，右边补1px白色至1026×328，不裁切建筑。
- 视频518,304字节（约506KiB），保留142帧；原素材区间4.26秒，浏览器报告播放时长4.23秒，结束后约280ms淡出。
- 原GIF副本：`frontend/server/seed-media/campus-intro-20261021/original.gif`，不会由公开站静态目录直接提供。
- 来源、剪辑区间、原件/成品SHA256：同目录 `source.json`。
- 公开成品：`frontend/visual-preview-20261013/assets/media/campus-intro.mp4`。
- 可复现构建脚本：`frontend/server/scripts/build-campus-intro-20261021.py`，需提供FFmpeg（含libx264）或安装imageio-ffmpeg；运行时网站不依赖Python或FFmpeg。

```text

```

## 代码与展示规则

新增 `assets/js/first-visit.js`、`assets/css/intro.css`，8个公开页面接入同一访问标记逻辑，后台不加载此功能。

- 只在新浏览器配置首次从 `/` 或 `/index.html` 进入时展示；带锚点的首页访问直接进入内容。
- 其他公开页面首次进入只登记已访问，不出现动画，之后返回首页也不突然播放。
- 同源持久标记 `scale-lab-intro-seen` 值为 `1`；在请求视频前写入，因此刷新、跳过、失败、切换页面、新标签、保存原存储重开浏览器均不重复播放。不随代码更新重置。
- 使用Web Locks做跨标签互斥，不能可靠取得资格时直接进入页面。未来正式域名应使用HTTPS；缺少锁支持时安全降级为不播放。
- 异步加载判断脚本，不阻塞HTML解析或DOMContentLoaded。脚本在导航开始1.5秒后才到达则放弃开屏，避免覆盖已加载的页面。
- 视频只在成功取得首次访问资格后设置src；已访问、减少动画、省流量、存储/锁不可用等情况无视频下载。
- 开屏白底、原比例居中；桌面最大960px，手机完整显示建筑。无声、不循环，始终提供“跳过，进入首页”及Esc。
- 首页内容正常在背后加载。覆盖期间锁定背景交互，结束恢复原inert、滚动和焦点；后续动态插入的按钮也纳入背景交互管理。
- 1秒未开始播放则直接跳过；媒体错误、自动播放拒绝立即退出；播放停滞最迟在6秒总期限退出。切换到后台标签或离开页面时移除开屏，防止返回后续播。
- 未额外显示静态降级画面；播放失败直接显示首页，减少等待。

实现参考：[MDN Web Locks API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Locks_API)、[MDN媒体自动播放指南](https://developer.mozilla.org/en-US/docs/Web/Media/Guides/Autoplay)。

## 使用与限制

- 首次体验：使用尚未访问的浏览器配置或无痕窗口打开 `http://127.0.0.1:3004/`。直接进入后台不会消耗首次播放资格。
- 成品单独预览：`http://127.0.0.1:3004/assets/media/campus-intro.mp4`，可用浏览器视频控件反复播放，不重置网站标记。
- 开发调试只需移除 `scale-lab-intro-seen` 这一项后重新打开首页，不应清空所有站点数据；正式用户无需此操作。
- 清除站点数据、换浏览器、换域名/端口、无痕新会话属于独立存储，可能再次播放。
- 重开浏览器的测试通过保存并恢复原localStorage模拟，不宣称进行了操作系统重启测试。
