# 登录入口与柔和页脚布局优化验收

日期：2026-10-21。依据：用户反馈登录页辨识度不足、页脚深色过渡仍生硬，要求校园图移入版权行，并同步减淡管理端配色。本稿更新同日第一轮视觉方案中的“深色页脚与页脚上方独立插画”设计。

## 完成内容

### 管理端登录页

- 加入现有实验室Logo与“华中师范大学 · 人工智能教育学部”，无需新制图标。
- 桌面使用最大1040px的双栏入口：左侧介绍实验室平台、新闻活动/学术档案/媒体维护用途并展示校园图，右侧为登录表单。
- 明确标题“网站内容管理”，补充指定人员使用、欢迎语、管理员分配账号及重置密码说明，并提供返回公开网站入口。
- 手机改为单栏，隐藏较长的功能列表及装饰图，保留品牌、平台说明和登录表单。
- 沿用登录表单ID、字段、错误提示和原认证逻辑；不展示初始账号或密码。

### 前台页脚

- 去掉页脚前独立的插画区，插画放入页脚底部版权行，位于“© 年份 实验室 · 学校”文字左侧。
- 插画等比例显示，桌面宽260px、高约53px；手机版权行自然上下排列，避免横向拥挤。
- 页脚背景由正文的 `#F7F8F5` 渐变至 `#E3EBEA`，标题深灰蓝、正文灰蓝，分隔线和关键词标签同步减淡。
- 全部公开页面共用 `renderFooter()`，重复加载设置和切换语言仍只保留1份插画。
- 原图来源、透明背景和静态视觉素材的维护方式沿用[前一轮记录](浅色学术配色与校园插画实施验收_20261021.md)。

### 工作台与导航

- 新增 `frontend/admin/studio.css`，侧栏背景改为 `#E7EFEE`，选中项 `#D0E1DF` 搭配青色细线；以实验室Logo替换原“S”占位标记。
- 主按钮使用 `#236A73`，状态分区使用浅青背景与深色文字；保留卡片白底和清晰的内容层级。
- 侧栏吸顶、短屏独立滚动、手机横向导航保持可用。
- 前台主导航文字不换行；1250px及以下使用菜单，避免截图中各导航项被挤成多行。
