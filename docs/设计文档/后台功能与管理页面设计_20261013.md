# 内容管理后台：功能与管理页面设计

更新日期：2026-10-13。状态：待评审的实施方案。依据用户已确认的范围：首版纳入全部内容类型与站点设置；后台不超过 5 人；获准人员可自行编辑、核查和发布，操作需留痕；登录方式兼容专用账号与学校统一身份认证。

## 1. 首版功能范围

| 功能 | 首版应能完成的工作 | 发布前检查 |
| --- | --- | --- |
| 成员 | 新增、编辑、排序、归类、归档；管理公开简介、照片、主页、校友去向 | 身份、资料来源及各字段展示授权 |
| 新闻 | 编辑标题、摘要、正文、事件日期、封面；预览和发布 | 日期、来源、链接及中文文案 |
| 论文 | 编辑题名、作者、刊物、年份、发表阶段、DOI／外链、标签 | 来源与发表阶段；未来年份不得自动写成“已发表” |
| 项目 | 编辑名称、编号、资助类别、负责人、起止日期、项目进度 | 名称和编号一致；“在研／结题”与内容发布状态分开 |
| 研究方向 | 编辑中英文标题与介绍、排序、关联论文／项目 | 对外研究方向口径已确认 |
| 活动与相册 | 编辑活动日期、说明、照片顺序、封面 | 照片来源、说明、版权和人物公开授权 |
| 媒体库 | 上传、预览、替换、停用图片；填写替代文本、来源和授权记录 | 上传格式、大小和文件类型检查；引用关系可查 |
| 站点设置 | 编辑当前网站名称、Logo、简介、联系渠道、首页精选内容 | 基础信息与公开授权；修改前可预览 |
| 账号与记录 | 管理员启停账号；查看编辑、发布、撤回记录 | 每次操作关联具体账号和时间 |

中文字段优先完成；英文可以同步录入。单条内容的英文版需单独标记完成核查，未完成英文版时中文仍可发布。

## 2. 后台页面

建议以 `/admin` 作为后台入口，最终路径可在实现时确定。

| 页面 | 主要内容与操作 | 访问者 |
| --- | --- | --- |
| 登录页 | 登录、退出、会话失效提示；支持将来切换认证方式 | 获准人员 |
| 工作台 | 待完善内容、待核查来源／授权、最近发布、最近撤回 | 全部后台人员 |
| 成员列表／编辑页 | 分类筛选、排序、中文及英文资料、照片与字段公开控制、预览 | 全部后台人员 |
| 新闻列表／编辑页 | 草稿、事件时间、正文、封面、预览、发布 | 全部后台人员 |
| 论文列表／编辑页 | 年份、发表阶段、DOI、标签及来源；查重提示 | 全部后台人员 |
| 项目列表／编辑页 | 项目进度、编号、日期、关联方向 | 全部后台人员 |
| 研究方向列表／编辑页 | 排序、双语内容、关联成果 | 全部后台人员 |
| 活动与相册列表／编辑页 | 活动资料、照片增删排序、封面 | 全部后台人员 |
| 媒体库 | 图片上传、来源、替代文本、授权与引用位置 | 全部后台人员 |
| 站点设置 | 名称、Logo、联系信息、首页精选、双语状态 | 全部后台人员 |
| 操作记录 | 按账号、内容、动作和时间查询 | 全部后台人员只读 |
| 账号管理 | 邀请／停用账号、指定管理员身份 | 管理员 |

每个编辑页复用同一组操作：**保存草稿 → 查看发布前检查 → 预览 → 发布／撤回 → 查看历史**。同一人可以完成全部步骤；界面仍显示来源与授权检查结果，并记录操作者。

## 3. 内容状态与权限

- 内容状态：`draft`（草稿）、`published`（已发布）、`archived`（已归档）。若以后需要独立审批，再增加 `in_review`；首版不强制双人审批。
- 中文和英文各有独立的就绪状态；中文发布不依赖英文。英文公开页只展示英文已核查的内容。
- 内容管理人员：所有进入后台的获准人员都能编辑、预览、发布和撤回内容。
- 管理员：还可启停后台账号并修改账号权限。管理员同样具备内容管理能力。
- 发布后再编辑应生成新的草稿修订，公开页继续显示上一次已发布版本，直到新修订发布；撤回则立即停止公开展示。

## 4. 后端模块及其接口

为避免页面、公开接口和后台各自实现发布规则，建议让内容模块集中处理 `saveDraft`、`preview`、`publish`、`withdraw`、`listPublished`。调用方只需传内容类型、内容 ID、语言和操作账号；模块内部完成版本冲突检查、字段校验、公开字段裁剪和记录操作日志。

认证模块只向业务模块提供“当前账号及其权限”。它可以有专用账号和学校统一身份认证两种适配器；具体认证方式后定，不影响内容模型。文件存储模块只暴露上传、读取和停用操作；本地开发与云端存储在同一接口后切换。

## 5. 接口与验收场景

公开接口保留 `/api/v1/*`，只返回已发布内容。管理接口使用 `/api/admin/v1/*`，按登录会话授权，提供各类内容的列表、详情、保存、预览、发布、撤回，以及媒体、设置和操作记录。应写明分页、筛选、版本号、校验错误和未授权响应。

首版验收至少走通：

1. 后台人员创建成员、新闻、论文、项目、研究方向和活动草稿，添加图片并保存。
2. 同一人检查来源与授权、预览、发布；公开网站和公开接口同步出现该版本。
3. 已发布内容修改后，公开页保持旧版本；新版本发布后才切换。
4. 撤回内容或照片授权后，公开页与接口不再显示相应内容／图片。
5. 中文内容可发布而英文留在草稿；未经审核的英文内容不出现在英文页。
6. 普通后台人员不能管理账号，未登录请求不能进入管理接口；所有写入与发布动作可在操作记录中追溯。
