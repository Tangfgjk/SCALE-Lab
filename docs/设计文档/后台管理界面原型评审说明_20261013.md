# 后台管理界面原型评审说明

更新日期：2026-10-13。状态：**整体布局已确认采用 A · 侧栏工作台**；原型文件位于 [`frontend/admin-prototype.html`](../../frontend/admin-prototype.html)，只使用示例数据，不连接登录、API 或数据库。

项目现有的 8080 静态服务运行时，打开 `http://127.0.0.1:8080/admin-prototype.html`。若未运行，可在 `frontend` 目录执行 `python -m http.server 8080`，然后访问上述地址。

## 设计目标

让不超过 5 位实验室内容管理人员快速找到待核验内容，完成编辑、预览和发布。视觉沿用现有公开网站的深海军蓝、亮蓝、青色强调、细线栅格和宋体标题；后台提高信息密度与状态可见性。

## 三种布局方案

| 方案 | 布局与首要任务 | 适合情况 | 需要评审的取舍 |
| --- | --- | --- | --- |
| A · 侧栏工作台 | 固定左侧模块导航，首页展示待办、概况和最近更新 | 模块多、频繁跨模块编辑；希望后台入口稳定 | 小屏幕时模块导航为横向滚动，需评估手机上是否方便 |
| B · 编辑台 | 顶部导航、宽版内容表格和简洁的编辑式排版 | 主要在桌面浏览器整理资料；偏好接近公开站的学术气质 | 模块较多时顶部导航需要横向滚动 |
| C · 任务队列 | 左侧窄导航、待办队列与当前任务详情并列 | 每天先处理核验和发布任务；重视流程引导 | 需要真实待办规则；移动端隐藏第二列任务队列 |

**已确认决定**：A 作为正式后台的基础布局。保留 A 的侧栏、工作台和模块入口；C 的任务面板与 B 的排版只保留为可选参考，不作为已确认需求。

## 原型中可评审的内容

- 模块入口：工作台、成员、新闻、论文、项目、研究方向、活动相册、媒体库、站点设置、操作记录、账号管理。
- 内容列表：搜索、状态筛选、状态标识、更新时间、进入编辑区。
- 编辑区：中文／英文切换、基本字段、来源或授权依据、发布前检查、预览、历史记录与操作按钮的位置。
- 发布规则的视觉表达：已发布版本与新草稿分离；中文可先发布；待核验内容无法点击发布。
- 三种方案可通过底部切换条、左右方向键或 `?variant=A|B|C` 对比。

按钮中的保存、发布、撤回均只是提示；输入不会持久保存。页面中的条目、日期和统计数字只是界面示例，不代表实验室真实内容或项目进度。

## 后续逐模块细化

整体布局已确认。原型中的编辑区只说明共同操作位置，不能直接当作各模块最终表单。成员需要字段级公开授权，活动相册应以图片顺序、封面与授权为中心，论文需要作者、刊物、DOI、发表阶段等专门字段；项目、研究方向、新闻和站点设置也按各自数据结构实现。具体字段、校验和交互在对应模块开发时复核。

正式开发时将 A 的结构拆成页面与组件，并与数据库、管理 API 和认证模块对接。此原型文件保留为本轮设计决策的参考，不直接当作生产代码。
