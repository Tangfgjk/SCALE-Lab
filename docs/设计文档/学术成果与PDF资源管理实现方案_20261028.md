# 学术成果与 PDF 资源管理实现方案

日期：2026-10-28。基于 V5，兼容现有论文、方向、项目和图片。

## 范围

1. 后台“论文成果”升级为“学术成果”，类型为论文、专利、软件著作权；沿用 publication 内容身份与修订发布流程，原论文自动按论文类型读取。
2. 资源库分图片与 PDF；PDF 独立存储记录和路由，不允许混入图片选择器。上传先私有保存，记录来源、版本、页数、大小、校验值；公开许可、启用、停用独立于成果发布。
3. PDF 上限 25 MB，解析真实 PDF，拒绝加密和主动内容，解析在有超时限制的 worker 中完成。相同文件可复用，换文件生成新资源与新成果修订，不覆盖旧字节。
4. 成果编辑支持图文、封面、PDF 附件、精选与顺序、类型特有字段、方向/项目/成员关联。关联存入修订；未公开的关联对象不向访客暴露。
5. PDF 公开 URL 与成果 slug、语言绑定，只有当前已发布修订引用且文件允许公开并启用时可预览/下载。保存草稿、私有引用、文件停用或该成果撤回不能绕过此规则。
6. 前台增加学术成果详情、分类/年份/方向/关键词筛选、精选区、引用复制、PDF 打开/下载入口。首页保持概览，研究页增加区块导航；模拟交互明确标注并后移。
7. 静态导出遍历成果详情并仅复制公开附件。Pages 是独立快照，撤回后需重新导出部署，动态访问控制无法追溯撤销已经下载或部署的静态副本。

## 数据与验收

新增迁移，保留旧迁移和真实内容；成果扩展字段及图文在修订中保存，附件和关联使用外键映射。首次应用到真实库前成套备份。

隔离测试重点：伪 PDF、加密/主动内容、上传大小、CSRF、草稿不公开、同一 PDF 多成果复用、按成果/语言访问、替换后旧发布版本仍可读、发布后的切换、撤回/停用失效、图片授权、双语事实、旧论文兼容、筛选与静态导出。未提供真实专利/软著/PDF，不自动编造发布内容。
