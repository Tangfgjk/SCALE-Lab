# 校园素描上色首次访问开屏动画方案

日期：2026-10-21。状态：用户已确认，现已实现；成品、13组验收与降级细节见[实现记录](../进度文档/首次访问校园开屏动画实现与验收_20261021.md)。下文保留原设计方案。

## 素材确认

用户提供的 `codex-clipboard-789a3469-9812-47b6-a2a7-93608538e570.jpg` 虽然扩展名是jpg，文件头为GIF89a，实际为多帧GIF：1025×328、224帧、每帧30ms、总时长6.72秒、约8.55MiB。消息中的白色静态预览不能代表完整动画。

用户描述的效果是校园建筑从素描逐步上色，并明确要求去掉最后“人工智能教育学部”的片尾。实施时须逐帧检查文字出现位置，确认截取结束点；本轮仅确认格式及帧信息，不宣称已完成逐帧视觉检查或裁剪。

## 推荐体验

1. 仅在访客首次从首页进入站点时播放，播放一次后直接显示已在背后加载的首页。
2. 白色画布承载原动画，建筑保持原比例居中，保留完整横向构图。桌面最大宽约960px，手机宽度接近屏幕减去左右16px，不拉伸、不裁切主体。
3. 完整保留“素描—上色—完成”的主线，去掉学部片尾，不添加声音或循环。建议成片4～5秒，实际按文字出现帧和观看节奏确定；不能为凑时长删掉关键过程。
4. 完成画面短暂停留约0.4秒，再用约0.25～0.35秒淡出显示首页，不强制重定向或再打开页面。
5. 从开始就提供“跳过，进入首页”按钮，支持鼠标、触屏、键盘及Esc；不强制用户等待。

## “只出现一次”的含义

推荐使用同源持久标记，含义是**同一浏览器配置首次访问当前站点**，而非每次刷新、开新标签或重启浏览器都播放。

| 情况 | 默认行为 |
| --- | --- |
| 从首页首次进入 | 播放一次，可随时跳过 |
| 刷新、切换页面、返回首页、新标签、重开浏览器 | 不再播放 |
| 第一次通过新闻/成员详情等直链进入 | 直接阅读并登记已访问，之后不突然插入开屏 |
| 管理后台 | 不参与开屏逻辑，不阻断管理任务 |
| 另一浏览器、另一配置、无痕会话、清除站点数据 | 视为独立环境，可能再次播放 |
| 本地开发地址换到云端正式域名 | 不同站点存储，正式域名可以首次播放 |
| 用户偏好减少动画 | 直接显示页面，并登记已访问 |
| 存储不可用、跨标签互斥不可确认 | 优先直接显示页面，避免重复播放 |

不默认设置每日/每周重播，也不因动画素材更新自动重置标记。用户主动跳过、加载失败或播放中刷新，也视为本次已访问；进入播放流程前写入标记，避免刷新循环。

## 实现约束

- 使用首页之上的临时覆盖层，正常页面从一开始就在后台加载；结束或异常时移除覆盖层，恢复滚动、焦点及页面交互。
- 源GIF较大，不直接作为全站首次加载必下资源。实施时制作去片尾的短视频，准备适合浏览器播放的编码及首帧/末帧静态降级图；成品大小以实际编码质量测试为准，不提前保证压缩比例。
- 无声、自动播放、仅一次；已访问用户不创建视频资源请求，避免持续下载和占用。
- 首帧不能在约1秒内开始、解码失败、播放被阻止时直接跳过。覆盖层从出现起设置约6秒总超时，确保不会永久挡住首页。
- 跨标签页采用同源互斥策略，支持时使用浏览器锁；无法可靠获得一次播放资格时降级为不播放，不以多个标签同时展示为代价。
- 跳过按钮有明确名称与可见焦点，背景暂时不可交互；结束恢复焦点至首页合理位置，不留下透明拦截层。
- 首页正常内容不依赖开屏脚本才能显示；关闭JavaScript仍能进入原有页面框架。

## 实施顺序与验收

1. 检查完整帧序列，提供去掉学部片尾的成片预览，确认首尾帧、速度、尺寸和体积。
2. 接入首次访问与降级逻辑，保持后台、详情直链正常使用。
3. 验证首次播放、刷新不播、新标签不播、重启后不播、跳过、减少动画、慢网/失败超时及移动端比例。
4. 检查已访问情况下无动画下载，覆盖层移除后菜单、链接、滚动、返回顶部可正常使用。
5. 更新来源与实现验收文档，再交付用户实际体验。

可选但不默认加入：在页脚提供低调的“重播开场”入口，由用户主动触发；默认方案保持页面简洁。
