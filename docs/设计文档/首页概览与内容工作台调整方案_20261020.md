# 首页概览与内容工作台调整方案

日期：2026-10-20。实施基线：V4-20261017 / 37f3905。

## 公开网站

- 导航顺序：首页、团队成员、研究成果、新闻动态、实验室文化、加入我们；桌面、移动菜单及页脚保持一致。
- 首页只展示最新三条新闻、最多三个研究方向与最多三个活动相册封面，各区域提供明确的更多入口。最新新闻按新闻日期排序，不被后台精选配置改变顺序。
- 增加新闻列表页 `news-list.html`，按日期浏览全部已发布中文/英文新闻，支持标题摘要搜索、年份筛选和每页10条；详情返回列表。现有 `news.html?slug=...` 链接继续有效。
- 将文化页的加入模块移至 `join.html`。增加欢迎语、研究兴趣、协作期望、联系建议和现有教师联系方式；不承诺招生名额、资格或录取结果。
- 文化价值观采用有序的开放版式、细分隔线、序号和留白；活动区为可扩展的影像网格，无图片时提供简洁空态。首页按钮改为更轻的圆角与文字链接组合，保持学术气质和清晰对比。

## 管理工作台

- 新闻、成员、研究方向、论文、项目、相册统一服务端每页10条，按中文最新修订显示草稿待核、已核查待发布、已发布、有新草稿四种状态；用状态分区按钮过滤，保持关键词搜索。
- 测试内容按明确的测试slug前缀识别，提供“业务内容/测试内容/全部”筛选。此为兼容旧测试数据的识别规则，不删除记录，不根据标题里的普通“测试”二字判断真实业务。
- 媒体库每页10张，保留已有文件夹、状态与搜索条件。账号最多5个不强行分页；站点设置是单例，不作为内容列表分页。
- 新旧接口保持data数组兼容；有分页参数返回meta.total/page/pageSize及各状态计数，状态计算按中文修订比较，不使用全局version误判。

## 六篇公众号原文草稿

目前六篇公开新闻为此前整理稿。用户随后明确确认“可以整篇复制”，现已按完整来源快照保存六篇v3原文草稿，保留已有v2公开稿，由用户编辑后决定发布。正文非空白文字序列核对一致，81处静态配图按原文顺序保留；公众号装饰动图不插入本站编辑器。详见《六篇公众号全文草稿来源与导入记录_20261020》。

## 验收

- 首页3条、新闻列表6条且详情可返回；全部公开页面导航一致，移动宽度无溢出。
- 后台每页至多10条，搜索/状态/测试筛选正确，跨页ID不重叠，状态总数对应内容范围。
- 原有新闻发布链路及双语状态隔离回归；不修改六篇正式新闻正文与公开修订。
- 记录实现进度、测试结果及原文资料待提供事项。
