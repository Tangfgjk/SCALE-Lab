# 新闻摘要封面重复展示修复

日期：2026-10-20。用户反馈：新闻首段和图片重复出现，截图为全球前2%科学家榜单新闻。

## 复现与定位

使用diagnosing-bugs流程，在真实详情页检查DOM：summaryRepeated=true、coverRepeated=true、articleBodies=1，抛出`FAIL duplicate article intro`。因此不是整份正文重复挂载。

候选原因按顺序为摘要重复、封面与正文图重复、正文数据重复。实际数据与DOM验证前两项成立：`frontend/shared/news-article.js`此前无条件先渲染摘要和封面，再渲染富文本正文。六篇原文的首段与图片已经在正文中，用户修改后仍会被外层元数据再次展示。

## 修复规则

- 摘要去掉空白后已出现在渲染正文中时，不在详情页头部额外显示；独立摘要保留。
- 封面assetId已在正文图片节点中出现时，不再额外显示封面；正文没有使用的独立封面保留。嵌套图片同样处理。
- 正文内容、图片顺序、人工编辑格式保持原样，不对正文内部主动去重。
- 公开详情、后台实时预览、后台已保存预览共用同一修复。首页和新闻列表继续使用摘要字段，不改写数据库或已发布修订。

## 回归结果

浏览器回归文件：`frontend/server/tests/news-article-duplicate.browser.js`。在加载真实新闻组件的页面上通过Playwright `browser_run_code_unsafe`以filename方式执行，不应作为普通Node脚本执行。

- 修复前，回归抛出`FAIL: summary repeats body introduction`。
- 修复后：重复摘要/封面隐藏；独立摘要/封面保留；格式化正文和嵌套图片识别正确；正文内有意重复的段落不被删除；纯文本正文、重复渲染也通过。
- 六篇真实已发布新闻逐篇检查，均无页头摘要或封面与正文重复。正文图片数按日期从新到旧为1、2、14、2、8、11。
- 后台榜单新闻的实时预览和已保存预览均为summary=0、cover=0、bodyImages=1。
- 390px手机视口无横向溢出，榜单图片仅出现一次。截图：`frontend/server/storage/import-reports/news-duplicate-fixed-mobile-20261020.png`。
- JS语法、git diff --check通过。

本次只修复显示逻辑，六篇新闻的版本与发布时间保持原样。后续录入时仍可使用摘要作为首页概览，正文正常保留开头段落，不要求编辑人员手动删除内容来迁就页面渲染。
