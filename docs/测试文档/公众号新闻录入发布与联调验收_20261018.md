## 交付结果

六篇中文新闻及11张原报道静态图片已通过管理接口完成草稿保存、图片公开登记、预览、当前修订核查与发布。所有操作使用管理员身份与 CSRF 校验，保留媒体与新闻操作记录。内容、来源和配图选择依据[采编方案](../内容文档/王志锋相关新闻采编方案与来源清单_20261018.md)。

用户在方案确认后要求依公众号发布时间排序，已全部采用原文发布日期作为新闻日期，并按从早到晚执行发布；首页仍按最新新闻优先显示。会议的6月17日、培训的2月28日等实际发生日期保留在正文，不冒充原文发布日期。详情页和工作台日期字段文案改为“新闻日期”，工作台说明转载报道可使用原文发布日。

首版为结构化新闻和成果导读，篇幅按内容适当压缩，没有复制公众号装饰、关注引导或论文全文。两篇班主任报道互相链接；论文保留作者顺序、通讯作者、实验边界及 DOI；榜单新闻不扩写为同时入选终身和年度两类榜单。已保留图像署名、图注、替代文字和可见的原文链接。

## 迁移与维护

- 采编数据：`frontend/server/seed-content/wechat-news-20261018.js`。
- 原图与来源清单：`frontend/server/seed-media/wechat-news-20261018/`，包含11张所选图片和 `sources.json`；清单记录原账号、发布时间、原图URL、原图序号、尺寸与SHA-256。
- 导入脚本：`frontend/server/scripts/import-wechat-news-20261018.js`。默认保存草稿，加 `--publish` 后核查发布；密码通过环境变量提供。
- 媒体库位置：默认图片库 → 新闻素材 → 王志锋相关新闻。封面与正文复用同一媒体ID，避免重复上传和连续重复展示同一图片。
- 本地执行报告：`frontend/server/storage/import-reports/wechat-news-20261018-publish.json`；后台预览报告为同目录的 `wechat-news-20261018-draft.json`。
- 本地截图：同目录 `wechat-news-home-order-20261018.jpg` 与 `wechat-news-paper-mobile-20261018.jpg`，仅作为本地验收证据。`storage/` 被Git忽略；数据库、上传媒体和报告需要独立备份。

在全新数据库完成迁移与管理员初始化、启动服务后，于 `frontend/server` 设置 `ADMIN_LOGIN`、`ADMIN_PASSWORD`、`TEST_BASE_URL=http://127.0.0.1:3004`，执行：

```powershell
node scripts/import-wechat-news-20261018.js
# 检查六篇后台草稿预览后：
node scripts/import-wechat-news-20261018.js --publish
```

重复运行相同数据会跳过已发布内容，不新建修订、不刷新实际发布时间。若管理员已修改文章，脚本默认停止，避免覆盖人工编辑；只有明确需要恢复采编数据并检查差异后才加 `--update-existing`。已有图片被停用、归档或撤权时脚本停止，需在媒体库处理。
