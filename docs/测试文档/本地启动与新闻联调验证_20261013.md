# 本地启动与新闻联调验证

日期：2026-10-13。范围：M0 与 M1 中文新闻纵向链路。以下命令在 `frontend/server` 执行；密码仅通过本机环境变量输入，不写入仓库。

## 本地环境

- Node.js ≥18；已安装 `express`、`pg`。
- Docker Desktop Linux 容器 `scale-lab-postgres`，镜像 `postgres:17.11`，数据库与用户均为 `scale_lab`，数据卷 `scale-lab-pgdata`，端口仅映射 `127.0.0.1:5433`。
- 新机器可参考 `frontend/server/compose.local.yml` 创建同配置的开发数据库；密码由本地 `SCALE_LAB_DB_PASSWORD` 环境变量提供。当前机器已有运行中的专用容器，占用同一端口，不要同时启动 Compose 副本。
- 本地初始管理员登录名 `admin`。开发密码按用户指定设置；进入云端前需要重置，并使用 HTTPS、独立数据库凭据和备份策略。

在 PowerShell 中设置本地连接变量后执行：

```powershell
$env:DATABASE_URL = 'postgres://scale_lab:<本地数据库密码>@127.0.0.1:5433/scale_lab'
npm run db:migrate
npm start
```

另一个终端打开 `http://127.0.0.1:3000/` 和 `http://127.0.0.1:3000/admin/`。如果 3000 已被原型服务器占用，可设置 `$env:PORT = '3001'` 再启动；前后台始终使用同一端口和同一来源。

首次初始化空库管理员时，设置 `ADMIN_LOGIN` 与 `ADMIN_PASSWORD` 环境变量，执行 `npm run db:bootstrap-admin`。该脚本拒绝覆盖已有同名管理员。迁移工具保存 SQL 校验和，重复运行不会重复建表。
