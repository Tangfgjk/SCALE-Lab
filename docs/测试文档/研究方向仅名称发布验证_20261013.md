# 研究方向仅名称发布验证

日期：2026-10-13。依据：实验室负责人在本项目对话中确认新版前台的三类研究方向**仅名称已核准**；简介与子主题继续待核。

## 实施

- 研究方向允许空摘要与空子主题；论文和项目摘要仍为必填。后台方向编辑页明确提示“仅核准名称时留空”。
- 通过后台创建、核查、发布三个中文方向：`教育数据挖掘`、`多模态课堂分析`、`教育人工智能理论与实证`。每条的摘要、正文、参与成员、子主题均为空，来源说明记录用户本次确认。英文方向未发布。
- 首页移除原来写死的三个方向简介及对应静态翻译，并将概览压缩为已确认的三个名称。研究页在空摘要和子主题时不渲染空段落或空栏目；无细节的卡片使用紧凑布局。
- 研究页移除包含 GCKT / MMKT 等具体技术主张的旧静态系统架构示意；带有“演示数据”说明的交互模块保留。

## 验证

1. `scripts/publish-confirmed-direction-names.js` 发布后读取公开 API：恰好三条、顺序 1–3、名称一致；`summary`、`body`、`participants` 均为空，`areas` 均为 `[]`；英文列表为空。
2. 浏览器 390px 宽度：首页三张方向卡只有名称，方向概览仅列出已确认名称；研究页三条方向没有摘要或子主题，旧架构技术文字不可见；页面没有横向溢出。
3. 现有发布脚本再次运行时复核已有数据，不新增重复内容。方向简介与子主题只有经过后续事实核验后才能另存修订并发布。
4. `npm run test:research`、`npm run test:bilingual-research` 通过；当正式三类方向已发布时，两套脚本只读检查方向，不创建占用 1–3 编号的合成方向，论文与项目的发布流程继续用合成数据验证。
