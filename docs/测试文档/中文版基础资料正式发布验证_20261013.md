# 中文版基础资料正式发布验证

日期：2026-10-13。环境：本地 Docker PostgreSQL、`frontend/server/platform.js`，公开站 `frontend/visual-preview-20261013`。

## 内容依据与范围

实验室负责人在本项目对话中明确确认：现有名称与 Logo、简介、办公地点和文化价值观均可公开展示。本文件记录首次发布：通过后台 API 正式发布中文版站点设置的名称、简称、简介、标语、学校、学部、办公地点和 Logo。文化价值观当时保留在公开站 `assets/js/data.js`；随后已纳入后台并发布，见[首页与文化文案后台发布联调验证](首页与文化文案后台发布联调验证_20261013.md)。联系邮箱和首页统计未获得确认，字段保持空白；英文设置尚未单独核查与发布。

## 操作与结果

1. 把现有 `scale-lab-logo.png` 上传到媒体库，填写中文／英文替代文本、署名和来源说明。记录版权公开依据及“无可识别人物”依据后启用，公开图片由 `/api/v1/assets/:id/file` 提供。
2. 以管理员账号通过 `PUT /api/admin/v1/settings/draft` 保存中文修订，随后执行 `/check` 和 `/publish`。发布修订 ID：`afbcb479-ac33-4573-abb3-4bd72cd65518`；Logo 资产 ID：`60feefb0-2d44-46d8-8b79-8792cb380474`。
3. 查询 `/api/v1/settings?locale=zh`：返回已确认名称和同一 Logo，邮箱为空、统计数组为空。查询 `/api/v1/settings?locale=en`：`data: null`。发布脚本对此做了断言并正常退出。
4. 将静态回退数据的学校和学部字段顺序纠正为 `华中师范大学` 与 `人工智能教育学部`，与后台发布值一致。
5. 浏览器检查 `http://127.0.0.1:3001/` 和 `/culture.html`：中文页面的品牌图片加载自上述媒体 API，图片实际加载宽度为 1920；页脚显示已确认简介、学校、学部和办公地点，未出现邮箱；文化页可见“严谨求知”至“开放成长”四项价值观，未出现失败的资源请求。

复现脚本：`frontend/server/scripts/publish-confirmed-baseline.js`。脚本需显式提供 `ADMIN_LOGIN` 与 `ADMIN_PASSWORD` 环境变量；已发布中文设置时会拒绝覆盖，不能当作日常重发命令。

既有 `test:settings` 是会创建并撤回合成站点设置的隔离测试，检测到正式中文设置后会主动停止，以免覆盖真实发布内容。因此本次发布后的验收使用只读公开接口与浏览器检查；该测试此前在无正式设置时已通过。
