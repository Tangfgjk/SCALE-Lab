# V3 新闻编辑器问题修复与回归

日期：2026-10-15
分支：`V3-20261015`

## 修复范围

1. 编辑器输入 `/people.html` 等本站路径时，保留相对路径，不把本地开发域名写入新闻正文。
2. 新闻草稿有未保存修改时，返回列表、切换工作台模块、新建另一篇新闻、退出或关闭页面均提醒。取消离开可保留编辑内容。
3. 后台实时预览、已保存修订预览和公开新闻详情页共用 `shared/news-article.js`、`shared/news-article.css` 和结构化正文渲染器。桌面与手机预览仍可切换宽度。
4. 已保存修订含停用或授权不完整的图片时，后台显示原因并禁用发布；点击发布前再读取最新图片状态，服务端继续执行最终授权校验。
5. 根 README 和前端 README 更新到 V3，记录编辑器构建方式与当前未完成范围。

## 原因记录

- 链接输入直接经 `new URL(value, location.origin)` 规范化，编辑器把相对路径转换成本地绝对地址。
- `dirty` 状态只控制核查与发布按钮，返回列表和侧栏切换没有使用它。
- 后台和公开页分别拼装标题、日期、摘要与封面，仅正文共用渲染器；图片授权状态也只在打开编辑器时读取一次。

## 复现与浏览器回归

| 场景 | 修复前 | 修复后 |
| --- | --- | --- |
| 输入站内链接 `/people.html` | 正文 JSON 保存为 `http://127.0.0.1:3004/people.html` | JSON 中保留 `/people.html`，预览仍可打开当前站点页面 |
| 修改正文后返回列表 | 直接离开，无提示 | 显示未保存确认；取消后正文保持原样 |
| 修改正文后切换到媒体资源 | 直接切换，无提示 | 显示确认；确认后切换，取消后留在新闻编辑器 |
| 打开含停用图片的已核查草稿 | 发布按钮仍可点击，服务端才拒绝 | 明确提示图片状态，发布按钮禁用 |
| 后台实时和已保存预览 | 仅正文与公开页共用渲染器 | 标题、日期、摘要、封面和正文共用文章组件及样式 |

本地端口 `3004` 的浏览器验收没有控制台错误。390px 手机视口下详情页没有横向溢出；封面和正文图在实际发布页正常加载。用于浏览器发布验收的合成新闻已撤回，合成图片已停用。

本地开发库中检查 `content_localizations.extra_json` 是否含 `127.0.0.1`，受影响记录数为 0；因此本次不需要更改历史新闻修订。
