# 站点设置双语发布与公开页联调验证

日期：2026-10-13。环境：本地 Docker PostgreSQL 17（`127.0.0.1:5433`），`frontend/server/platform.js`（`127.0.0.1:3001`）。本文件记录正式资料发布前的合成数据隔离测试；后续中文版真实基线已发布，见[中文版基础资料正式发布验证](中文版基础资料正式发布验证_20261013.md)。

## 实现范围

- `005_site_settings.sql`：单例版本、中英文修订、各语言公开指针。
- `settings.js`：草稿、核查、预览、发布、撤回、修订历史和只读公开接口；写入审计事件。
- `frontend/admin/settings-admin.js`：后台设置表单及状态；Logo 选择来自获准媒体，首页精选使用已发布内容的标识。
- 公开站 `assets/js/main.js`：按语言获取已发布设置，更新首页简介、单位、地点、Logo、统计区、文化页愿景与页脚；精选新闻和方向按配置排序。没有发布设置时维持现有站点名称与视觉基线，隐藏未经核验的邮箱和统计数字。

## 已执行验证

1. `npm run db:migrate`：`005_site_settings.sql` 成功应用。
2. `npm run test:settings`：通过。覆盖匿名管理接口 401、来源必填、未授权 Logo 核查失败、未核查修订不可发布、中英文分别发布、英文共享事实不一致时拒发、中文共享事实更新后英文下线、撤回后公开接口返回 `data: null`。
3. 浏览器后台：打开 `http://127.0.0.1:3001/admin/`，进入“站点设置”，确认表单、历史、状态及各操作按钮实际加载。测试结束后合成修订已从数据库清除。
4. `node --check`：`settings.js`、`settings-admin.js`、公开站 `main.js` 均通过语法检查。

## 后续补充验证

- 后续浏览器导航已恢复：检查公开首页中文和英文状态，未发布设置时统计区隐藏、页脚邮箱隐藏，页面继续显示既有名称基线。自动审批此前的容量错误没有影响最终这两项验收。已发布设置的真实页面显示和手机宽度布局仍待用正式核验内容验证。
- 已用负责人核验的正式名称、Logo、简介和地点完成中文真实内容发布与浏览器验收；邮箱、统计口径与英文译文仍待核，不进行补填。
- 首页精选论文已保存并校验，但首页尚无对应论文展示区；后续应决定增加精选论文区，或从设置表单移除该选项。
