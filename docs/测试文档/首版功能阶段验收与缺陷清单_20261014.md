# 首版功能阶段验收与缺陷清单

验收日期：2026-10-14。环境：本地 `platform.js` + Docker PostgreSQL 17，桌面浏览器 1440px 与手机浏览器 390px。范围为当前可运行的中文版公开站和 A 侧栏内容工作台；结论是**核心功能初步完成，可进入体验与细节修复阶段，尚未达到云端正式发布标准**。

## 已执行验证

| 范围 | 方法 | 结果 |
| --- | --- | --- |
| 新闻草稿、核查、发布、撤回、双语隔离 | `test:smoke`、`test:bilingual-news` | 通过 |
| 研究方向、论文、项目及双语发布 | `test:research`、`test:bilingual-research` | 通过；三类方向仅名称为正式内容 |
| 成员授权、字段可见性、双语与照片 | `test:members`、`test:bilingual-members`、`test:member-photo` | 通过；媒体停用后头像立即隐藏，成员档案撤销后整条隐藏 |
| 媒体、相册、站点设置、账号与审计 | `test:media-albums`、`test:settings`、`test:accounts` | 通过；设置测试要求 `DATABASE_URL` 环境变量 |
| 公开站与后台入口 | `/`、`/people.html`、`/research.html`、`/culture.html`、`/admin/` | 1440px 与 390px 共 10 个页面场景均 HTTP 200，无页面脚本异常或横向溢出 |
| 教师资料与肖像 | 公共 API、照片文件 HTTP、浏览器与后台表单 | 可见王志锋、刘晓雪、熊宇轩；3 张头像均加载。后台可选择已启用媒体并查看照片字段授权；复跑导入仍为 48 位成员 |
| 数据库迁移 | `npm run db:migrate` | 既有迁移校验通过，新增 `007_member_photo_asset.sql` 应用成功 |

本轮已修复：教师卡片原来统一隐藏照片；成员模型未与媒体资源关联；后台照片授权入口被固定禁用；手机端教师照片与正文并排导致文本列过窄。现在采用媒体 ID、授权门槛、公开时即时状态检查和手机端纵向卡片布局。

## 仍需处理的缺口

| 优先级 | 事项 | 影响／下一步 |
| --- | --- | --- |
| 高 | 云端部署尚未实施；当前登录凭据仅供本地开发 | 选择云服务器、域名、HTTPS、密钥与备份恢复方案，发布前更换初始密码 |
| 高 | 联系邮箱、真实新闻、活动相册图片尚无完整正式内容 | 补充可核对来源和内容，经后台录入；相册图片逐张登记来源和人物字段 |
| 中 | 英文版框架有双语流程，但正式英文资料尚未翻译发布 | 由内容负责人确定翻译文本后独立核查和发布 |
| 中 | 研究方向简介、子主题与参与成员仍未确认 | 保持仅名称展示，不从教师个人研究方向自动推断 |
| 中 | 成果只录入代表性论文和部分项目，DOI、项目全称与来源状态冲突项未补齐 | 分批扩充，并保留原始来源、状态和时间依据 |
| 中 | 管理列表有 100 条读取上限，完整分页和内容关联仍未做 | 真实内容增长前实现分页、筛选、首页精选与内容关联 |
| 低 | 当前主要是冒烟测试和两种视口检查，键盘全流程、屏幕阅读器和多浏览器回归尚未完成 | 体验阶段按场景逐页记录问题并修复 |

## 结论与下一阶段

当前可由实验室使用者体验“浏览团队与成果 → 查看来源”“内容人员登录 → 编辑草稿 → 核查发布 → 撤回”“媒体上传 → 授权启用 → 成员／相册引用 → 停用”的闭环。下一阶段先做真实内容补齐、完整页面体验与可访问性修复，再进行部署和备份恢复演练。此结论不等于所有首版需求已全部验收完成。
