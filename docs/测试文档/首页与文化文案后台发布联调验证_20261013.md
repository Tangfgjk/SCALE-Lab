# 首页与文化文案后台发布联调验证

日期：2026-10-13。环境：本地 PostgreSQL 与 `http://127.0.0.1:3001/`。

## 本次实现

- 新迁移 `006_site_editorial.sql` 为站点设置修订增加首页标题三段、文化页标题、独立愿景和价值观数组。首页强调文字仍保留原有蓝色视觉；主文案换行保留分行。公开接口只返回当前语言已发布修订。
- 后台站点设置表单支持逐语言编辑、预览、保存、核查、发布和撤回。价值观每行一项，顺序决定公开页展示顺序；服务端限制最多六项并校验标题与说明。所有文本在公开页转义后渲染。
- 文化页不再把站点标语误作文化愿景。中文使用已发布字段；英文设置未发布时，继续显示原有静态英文界面文案。静态中文基线仍可在 API 不可用时回退。

## 已执行验证

1. `npm run db:migrate` 应用 `006_site_editorial.sql`；`node --check` 检查服务端、管理页和公开页 JS。
2. `scripts/publish-confirmed-editorial.js` 用用户已确认的现有文案保存中文修订、核查并发布。发布前读取公开接口，确认草稿不改变公开内容；空标题的价值观被 400 拒绝。发布修订 ID：`696d880f-1d70-4f79-b1b7-0ce7b5229f85`，全局版本 22。
3. 发布后 `npm run test:settings` 执行只读实时校验：中文标题强调文字、四项文化价值观、空邮箱、英文未发布及非法价值观校验均通过。已存在真实发布时，该脚本不运行会覆盖内容的合成发布测试。
4. 浏览器：首页标题呈两行并保留强调文字；文化页显示“严谨，也有温度。”、独立愿景及四项价值观。中→英→中切换内容正确，英文接口仍返回 `data: null`。后台表单载入已发布字段，预览列出四项价值观；390px 宽度无横向溢出。

- 继续处理研究方向、新闻、成果和成员的真实资料来源与公开授权；公开页其他固定说明文案仍需逐项识别是否纳入后台。
