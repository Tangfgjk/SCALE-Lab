# 新闻与研究内容双语发布验证

日期：2026-10-13。环境：本地 Docker PostgreSQL 17；应用 `http://127.0.0.1:3001/`。

## 验证结果

| 场景 | 结果 |
| --- | --- |
| 新闻中文与英文独立草稿、核查、发布 | `npm run test:bilingual-news` 通过；中文尚未公开时英文发布返回 `CHINESE_REQUIRED` |
| 新闻中文日期变更 | 中文新修订发布后英文接口 404，英文再次发布因事实不一致返回 `SHARED_FACTS_CHANGED`；审计出现 `news.invalidate_en` |
| 研究方向、论文、项目双语发布 | `npm run test:bilingual-research` 通过；两种语言列表／详情读取各自已发布修订 |
| 论文年份变更 | 中文发布新年份后旧英文立即下线；未经重新保存、核查的英文不能重新发布 |
| 成员双语及授权 | `npm run test:bilingual-members` 通过；英文先发被拒绝，简介授权撤销立即影响英文；中文身份类别变化使旧英文失效；档案授权撤销让双语一起下线 |
| 中文撤回 | 同一内容的中英文公开指针均移除；公开详情返回 404 |
| 原有回归 | `test:smoke`、`test:research`、`test:members` 均通过 |
| 后台浏览器 | 论文编辑表单显示中文／English 切换；新建前选择英文时被阻止，并提示先创建中文内容 |

测试创建的 `bilingual-*` 内容均以撤回公开指针结束，留存草稿与审计以便追溯。测试没有导入或公开旧资料。

## 复现

在 `frontend/server` 设置 `DATABASE_URL`、`ADMIN_LOGIN`、`ADMIN_PASSWORD`、`TEST_BASE_URL=http://127.0.0.1:3001` 后运行：

```powershell
npm run test:bilingual-news
npm run test:bilingual-research
npm run test:bilingual-members
npm run test:smoke
npm run test:research
npm run test:members
```

## 边界

本次双语范围为新闻、研究方向、论文、项目与成员。成员照片授权仍等待媒体库；相册、设置尚未接入。后台双语发布的完整人工浏览器流程、移动端页面和真实内容校核仍需后续验收。
