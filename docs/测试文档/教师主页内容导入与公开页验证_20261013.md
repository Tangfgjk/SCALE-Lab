# 教师主页内容导入与公开页验证

验证日期：2026-10-13。环境：本地 `platform.js`、Docker PostgreSQL，公开站 `http://127.0.0.1:3001/`。事实来源与采纳范围见[王志锋教师主页数据来源与采纳记录](../内容文档/王志锋教师主页数据来源与采纳记录_20261013.md)。

## 执行结果

1. `node --check frontend/server/scripts/import-faculty-profile-20261013.js` 通过。
2. 用已授权的本地管理员会话执行导入脚本，脚本通过后台 API 写入来源、授权、核查和发布记录；运行结束后公开 API 返回成员 46 人（导师 1 人、在读学生 20 人、校友 25 人）、论文 4 篇、项目 4 项。密码仅通过运行环境提供，不写入仓库。
3. 浏览器打开 `/people.html`，可见王志锋导师简介、在读学生和校友分组，以及来源主页按钮。页面显示 1、20、25 人，且修正了原来缺少事实依据的团队成员背景描述。
4. 浏览器打开 `/research.html`，可见三类仅名称的研究方向、4 篇论文和 4 项项目；4 篇论文外链到各自教师主页详情，4 项项目外链到主来源页面，共 8 个成果来源链接。
5. 将浏览器视口设为 390 × 844：团队页与研究页 `document.documentElement.scrollWidth` 均为 375，小于视口宽度 390；未发现横向溢出。
6. 再次执行同一导入脚本，公开 API 数量仍为成员 46 人、论文 4 篇、项目 4 项；未产生重复条目。`research.js`、`main.js`、`i18n.js` 的 `node --check` 和 `git diff --check` 均通过。
