# 新闻编辑与详情页联调验证

验证日期：2026-10-14。环境：本地 PostgreSQL 与 `frontend/server/platform.js`，先在 3002 端口验证，再重启日常使用的 3001 端口。

## 已验证

1. `npm run test:smoke` 通过：新闻不填写来源链接和说明，可创建草稿、核查、发布、修改后保留旧公开版、重新发布及撤回；读取草稿确认分类默认为 `news`，来源字段为空。
2. `npm run test:bilingual-news` 通过：中文先发布、各语言独立核查和发布、共享事实变化导致英文旧版失效。
3. 浏览器新建表单：URL 标识自动生成且创建前可编辑；分类输入不出现；来源两项明确为选填；标题、摘要、正文和日期有用途提示。
4. 在测试端口暂时发布已有联调新闻：首页出现标题与“阅读全文”链接；详情页读出已发布的标题、摘要、事件日期和正文。英文未发布时不展示中文正文；撤回后详情页也不展示正文。测试新闻已撤回。
5. 工作台其他常用表单的必填、选填和来源二选一标记已在浏览器检查；研究方向切换时摘要显示选填。手机宽度 390px 下，详情页不可用提示与返回链接无横向溢出。
6. 3001 端口健康检查通过，中文版公开新闻数为 0（联调新闻均已撤回）。

详情页只呈现纯文本正文；富文本、图片和独立新闻归档列表尚未纳入本次修改。
