# 媒体库与活动相册联调验证

日期：2026-10-13。环境：本地 Docker PostgreSQL 17，应用 `http://127.0.0.1:3001/`。

## 已验证

| 项目 | 结果 |
| --- | --- |
| 数据库迁移 | `004_media_albums.sql` 应用成功 |
| 非图片文件上传 | 即使声明 `image/png`，服务端解码失败并返回 `INVALID_IMAGE` |
| 待核图片隔离 | 新图片不可通过公开地址读取；未登记版权和人物公开依据时不能启用 |
| 图片处理 | 合成 PNG 上传后公开读取为 WebP；文件放在受控目录 |
| 相册发布 | 中文草稿、来源核查、发布后公开详情可见；英文修订独立核查并发布 |
| 引用查询 | 后台可查看图片被哪些相册修订引用 |
| 即时停用 | 停用图片后公开文件地址为 404；仅含该图的中英文相册详情均为 404 |
| 后台页面 | 浏览器检查媒体库的上传、资料、授权、引用区及活动相册列表；文化页无获准图片时显示待核提示 |

运行 `npm run test:media-albums` 可复现接口测试。测试只使用程序生成的纯色小图；测试相册已撤回，测试图片已停用。没有公开真实活动照片。
