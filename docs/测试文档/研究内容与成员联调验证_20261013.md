## 当前实现边界

- 研究方向正式口径采用用户确认的新版前台 3 类；编号限制为 1–3，旧 JSON 的“智慧课堂与人机交互”不作为独立公开类别。具体标题、简介、子主题的来源仍需逐条核查。
- 论文填写明确发表阶段，未来年份不能标为“已发表”；DOI 跨已发布条目检查重复。项目编号也在发布时检查重复。方向、论文和项目的关联关系尚未实现。
- 成员档案、简介、邮箱、校友去向分层授权；照片需要媒体文件、版权及人物授权，当前界面明确禁用。
- 公开首页研究方向卡片、研究页三个内容区和团队页已读取公开 API。公开站仍有其他静态说明、演示指标、相册占位和 `data.js` 依赖，后续 M3/M4 继续替换。
- 研究方向、论文、项目和成员的英文独立发布已在后续迭代接入，验证见[新闻与研究内容双语发布验证](./新闻与研究内容双语发布验证_20261013.md)。云端部署前必须更换本地开发账号密码并补齐备份、HTTPS 与权限设置。

## 本地重复验证

在 `frontend/server` 目录设置 `DATABASE_URL`、`ADMIN_LOGIN`、`ADMIN_PASSWORD` 及 `TEST_BASE_URL=http://127.0.0.1:3001` 后运行：

```powershell
npm run db:migrate
npm run test:smoke
npm run test:research
npm run test:members
```
