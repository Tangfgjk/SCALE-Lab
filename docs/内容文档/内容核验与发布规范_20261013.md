# 网站内容核验与发布规范

更新日期：2026-10-13。状态：建议稿。用户提供的[教师主页](https://faculty.ccnu.edu.cn/wangzhifeng/zh_CN/index.htm)作为初始来源，详见[来源核对记录](教师主页来源核对记录_20261013.md)；具体内容责任人与公开授权仍待确认（D04–D06）。后台获准人员可自行编辑、检查并发布。

## 1. 每条公开内容的最小记录

成员、新闻、论文、项目、研究方向、活动、首页统计数字均应记录：

| 字段 | 用途 |
| --- | --- |
| 内容负责人 | 提供并维护这条信息的人 |
| 来源及来源链接／文件 | 支撑事实的学校主页、出版记录、项目材料或活动记录 |
| 发布前核查人、核查日期 | 确认名称、时间、身份、数字和措辞；可与编辑人为同一人 |
| 公开状态 | 草稿、待审核、已发布、已归档 |
| 中文／英文内容状态 | 已核验、待翻译、待英文审核或不提供英文版 |
| 展示授权 | 人物照片、简介、联系方式、去向及活动影像所需的授权记录 |
| 最近更新日期 | 便于定期复核时效性 |

内部来源文件不应通过公开 API 返回；公开接口仅输出经批准的展示字段。

## 2. 按内容类型的核验要点

- **成员**：本人确认姓名、身份、研究兴趣、简介、照片及外部链接。私人邮箱和手机号默认不公开。校友去向单独取得确认；缺少确认时隐藏去向，而不是以占位符代替。
- **论文**：确认题名、作者、刊物／会议、年份、发表阶段和 DOI 或可信外链。在线发表、录用、预印本与正式发表使用不同标签；未来年份条目不可直接写成“已发表”。
- **项目**：确认项目名称、编号、资助类别、负责人、起止日期和当前进度。“在研／结题”是项目进度，不能替代网页的“草稿／已发布”。
- **新闻／荣誉**：记录事件日期、发布日期与可信来源，标题不得超出来源支持的结论。
- **统计数字**：说明统计口径、截止日期和来源；若无法核验，先不在首页展示。
- **活动与照片**：注明发生日期、照片说明、摄影或版权信息、人物公开授权。没有实拍素材时可删去画廊模块。
- **联系信息**：由负责人确认邮箱、地址及是否接受招生或合作咨询；避免展示未确认的私人联系方式。

## 3. 发布与撤回

建议流程：编辑草稿 → 检查事实、授权和语言 → 预览网页 → 发布 → 定期复核。拥有后台权限的人员可完成全部步骤，无强制第二人审批；系统记录每一步的账号、时间和检查结果。发布后修改应保留修订记录；撤回授权、错误内容或过期信息应能迅速下线，并记录处理人、时间和原因。

中文版正式发布前的阻断条件：可见 `@@@`；缺必要授权；成果无可靠来源却使用确定性表述；新闻日期或项目状态明显矛盾；关键联系入口不可用。英文页面可并行制作，但未经完整翻译与核查前不公开，也不阻断已合格的中文版。
