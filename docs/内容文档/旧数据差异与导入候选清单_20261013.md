## 导入决定

1. 两份旧数据均只作为待核验草稿候选；`reviewState=unverified`、`publicationState=draft` 不得被导入脚本自动提升。
2. 研究方向采用哪一组名称、排序和子主题，仍需负责人确认。
3. 论文发表阶段、项目进度、成员字段授权、照片版权、首页统计口径和联系邮箱逐项确认后才可发布。
4. 如需重新生成，在 `frontend/server` 目录执行 `node scripts/audit-legacy-data.js`。
