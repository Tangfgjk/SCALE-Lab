# 学术成果与 PDF 上传发布操作指南

日期：2026-10-28。

## 上传 PDF

进入工作台“PDF 文档”，上传不超过 25 MB 的普通静态 PDF，填写名称、文件夹、版本和来源。相同文件会复用已有记录，不覆盖原资料。上传后默认只在后台可见。

如文件可以公开，在“资料与公开设置”填写许可依据，勾选允许公开，并将状态设为“已启用”。允许公开不代表文件立刻出现在网站，还需要关联到已发布成果。

原文件不覆盖替换：需要新版文件时重新上传，在成果新修订中切换附件；旧版仍可在引用历史中追溯。

## 编辑成果

进入“学术成果”，新建内容并选择论文、专利或软件著作权。URL 标识自动生成，创建前可调整。填写标题、摘要、年份、作者/发明人/著作权人，以及对应类型的字段。正文支持现有富文本编辑器，可插入媒体库图片。

- 论文：刊物/会议、发表阶段、可选 DOI。
- 专利：类型、状态、申请号或专利号；未知类型/状态选“来源未注明”，不要使用网页发布日期代替授权日期。
- 软著：软件版本、登记号、登记日期。
- 代码仓库和演示链接独立于原始资料链接，可按需填写。

“从资源库添加 PDF”选择附件，填写访客可理解的名称。勾选“随成果公开”才会在前台出现；不勾选可作为内部参考保留。封面、关联方向/项目/成员均可选填。

## 发布和精选

保存草稿→核查当前修订→预览→发布。修改已发布成果时，公众继续看到旧版，直至新修订再次发布。

需要精选时勾选“设为精选成果”，数字排序越小越靠前。如“站点设置”已指定精选成果标识列表，需要同时调整该列表，其优先级高于成果自身精选开关。

前台“研究成果”支持类型、年份、方向和文字搜索；详情中可在线翻页预览、另开或下载 PDF。关联对象未发布或成员不允许公开资料时，不向访客显示对应入口。

## 撤回和停用

- 撤回成果：该语言详情及通过该成果访问的 PDF 地址不可访问；其他仍公开引用同一 PDF 的成果不受影响。
- 停用文档或撤销其公开许可：所有成果中的该文件立即停止向新请求提供，详情不再展示该附件。
- 仅取消某个附件的公开勾选：保存并发布新修订后生效。
- GitHub Pages 是独立静态快照，需要重新导出并部署；不会随本地后台实时更新。

无法预览时可用“打开 PDF”或“下载”；扫描件的文字是否可检索由原文件决定，本期不包含 OCR 或自动识别论文元数据。
