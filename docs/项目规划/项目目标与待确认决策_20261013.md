# 实验室网站：项目目标与待确认决策

更新日期：2026-10-13。状态：内部讨论稿。品牌、开发顺序、部署方向、后台人员权限和数据库引擎已确认；现有名称、Logo、简介、办公地点与文化价值观已获确认，王志锋教师主页来源内容已由用户授权用于本站；其他来源资料及云服务具体选型仍待确认。

## 1. 项目目标

为华中师范大学人工智能教育学部相关实验室建设一个易维护、可信、可访问的公开网站。访客应能迅速理解研究主题，找到团队成员及可核验的成果，并获得有效的联系或申请路径。

目标访客及其关键任务：

| 访客 | 关键任务 | 网站应提供的入口 |
| --- | --- | --- |
| 学术同行 | 判断研究是否相关，查阅代表成果 | 研究方向、论文与项目的来源链接、成员主页 |
| 拟报考学生 | 了解导师、课题与申请方式 | 团队介绍、研究方向、招生说明及联系方式 |
| 学校和合作伙伴 | 了解团队能力并发起合作 | 可核验的项目／成果、合作方向、联系信息 |
| 实验室内容管理人员 | 更新新闻、成员和成果，并在后台完成审核发布 | 明确的内容模板、发布检查和操作记录 |

近期交付目标已确认为**网站与内容管理后台同步建设**（D03）。公开发布仍须通过内容、授权、体验和运维验收。

## 2. 范围与边界

- 公开站范围：主页、团队、研究、文化、新闻与成果详情、联系或申请入口。详情页是否进入首个发布版本，需结合已确认的 D03 目标在首发范围评审时排期。
- 课堂行为识别组件仅展示明确标注的模拟数据；公开站不接入原始课堂音视频、可识别学生信息或真实行为记录。
- 内容平台的登录、编辑与发布属于本轮并行建设范围；现有只读 API 可运行不代表后台已经完成。
- 对外事实不得从占位符、演示指标或未核验的本地数据直接推断。

## 4. 建议的发布原则

1. 不展示 `@@@`、虚构照片、未核验成果或没有明确状态的“已发表”表述。
2. 涉及个人的资料按字段记录公开授权；撤回授权时有明确下线负责人。
3. 每项论文、项目与统计数字均有来源、审核人和最近核验时间；新闻的来源链接与说明可留空，但仍记录核查人与时间（2026-10-14 用户确认）。
4. 对外页面在手机和桌面上均可读、可操作；关键导航和联系入口可用。
