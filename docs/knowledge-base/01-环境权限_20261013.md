# 环境权限问题

### [LOCAL-ACCESS-001] 沙盒无法访问已运行的本地 Docker 与站点端口

#### 问题现象

普通执行环境中 `docker ps` 报 `open //./pipe/dockerDesktopLinuxEngine: Access is denied`，测试连接 `127.0.0.1:3001` 报 `connect EACCES`；无法据此断定 PostgreSQL 容器或网站服务已经停止。

#### 定位过程

1. 检查本地监听端口未得到有效结果，直接查询 Docker 受到命名管道权限限制。
2. 在获准的提升权限执行环境中查询，确认 `scale-lab-postgres` 容器仍在运行。
3. 同一环境启动 `platform.js` 并运行本地冒烟测试，数据库与网站连接恢复。

#### 根本原因

当前任务的受限执行环境禁止访问 Docker Desktop 命名管道和本机回环网络；这是执行权限边界，不是项目数据库配置或业务代码故障。

#### 解决方案

在需要访问该项目既有 Docker 容器或本地端口时，对明确的 Docker 查询、网站启动与联调测试请求对应执行权限；不把受限环境下的 `EACCES` 当成服务停机。

#### 验证方法

获准环境中的 `docker ps` 显示 `scale-lab-postgres Up`；`platform.js` 输出 `SCALE Lab platform: http://127.0.0.1:3001/`；九组自动化测试通过。
